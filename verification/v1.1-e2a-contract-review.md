## Scope

E2-A contains exactly two approved E0 DEX candidates:

1. D11 `cmc_dex_platform_list` → `GET /v1/dex/platform/list`
2. D4 `cmc_dex_token_price` → `GET /v1/dex/token/price`

D5 remains deferred. D15 and D17 remain excluded. No other DEX route is authorized by this review.

## Common invariants

- fixed production base `https://pro-api.coinmarketcap.com/public-api`;
- credential-free GET only;
- one MCP tool maps to one allowlisted route;
- no user-controlled host, path, method, header, or credential;
- strict schemas with `additionalProperties: false`;
- validation before network access;
- provider envelope and provider data preserved unchanged;
- existing stable error taxonomy applies; HTTP 429 remains `RATE_LIMITED`;
- shared 2 MiB response cap remains in force.

## Live evidence used to resolve platform identity

Eight minimal credential-free GETs were made on 2026-10-02 between 11:40Z and 11:46Z using Ethereum USDC as the deterministic token fixture.

`/v1/dex/platform/list` returned 244 platform records (65,517 bytes). All observed records had integer `id` and string `n`; three lacked `pltA`. Ethereum appeared as `id=1`, `n="Ethereum"`, `pltA="ETH"`. Observed platform names included spaces, parentheses, hyphens, and a non-ASCII character (`B² Network`).

For `/v1/dex/token/price`, both `platform=Ethereum` and `platform=ethereum` succeeded and returned `pid=1`. `platform=ETH` hit HTTP 429 and `platform=1` returned HTTP 500; both were classified as inconclusive and did not define accepted identity forms. Evidence establishes platform-name semantics and observed case-insensitive matching for Ethereum only.

## Contract: `cmc_dex_platform_list`

- Route: `GET /v1/dex/platform/list`
- Arguments: none
- Schema: strict empty object; unknown arguments rejected
- Query: none
- Description: get the list of blockchain platforms supported by CoinMarketCap DEX data; use it to discover platform names accepted by DEX tools
- Cache TTL: 900 seconds
- Output: provider envelope unchanged; platform DTO fields preserved verbatim
- Volume: no provider paging; shared 2 MiB client cap; observed response ≈65 KiB
- Live minimum shape: non-empty list; each item a mapping with integer `id` (not bool) and non-empty string `n`

## Contract: `cmc_dex_token_price`

- Route: `GET /v1/dex/token/price`
- Required arguments: `platform`, `address`
- `platform`: 1–64 characters; reject control characters, query delimiters, and leading/trailing whitespace; preserve case; do not normalize or freeze a local enum
- `address`: 1–128 characters, pattern `^[A-Za-z0-9_.:-]{1,128}$`; preserve case; no Ethereum-specific `0x` or fixed-length rule
- Query serialization: exactly `platform` and `address` using those provider key names
- Description: get current CoinMarketCap DEX price data for one token identified by platform name and token contract address; use platform-list to discover platform names
- Cache TTL: 15 seconds
- Output: provider envelope unchanged
- Live minimum shape: non-empty mapping whose `p` field is a finite number (not bool)
- Deterministic live fixture: Ethereum USDC
